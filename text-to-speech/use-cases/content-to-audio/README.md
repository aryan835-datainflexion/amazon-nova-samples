# Content-to-Audio Use Cases

These examples turn generated content into a two-speaker podcast with Amazon
Polly. Start with the focused command-line sample, then explore the experimental
studio if you need research, grounding, persistence, and a visual workflow.

| Sample | What it demonstrates | Status |
| --- | --- | --- |
| [Two-speaker podcast](two-speaker-podcast/) | Generate a host/co-host script with Amazon Bedrock and synthesize it with Amazon Polly | Ready |
| [Grounded podcast studio](grounded-podcast-studio/) | Add web research, source-backed claims, Knowledge Base retrieval, an informational fact-check report, and a browser UI | Experimental |

The grounded studio is a separate solution rather than a required progression.
It provisions additional AWS resources and its fact-check report does not
currently revise or block the script before synthesis.
